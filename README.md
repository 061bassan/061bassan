## Sobre

Desenvolvedor full stack, de Brasília. Trabalho com aplicações web de ponta a ponta: modelagem no
banco, regra de negócio no servidor e interface no navegador.

No dia a dia construo plataformas internas, painéis de gestão e sites institucionais, em React e
TypeScript no front, PostgreSQL e Supabase nos dados. Também cuido de autenticação, controle de
acesso e publicação em produção.
